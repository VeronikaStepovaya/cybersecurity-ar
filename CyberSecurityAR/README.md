# 🛡️ CyberSecurity AR

## Симуляція кібератак та захисту в доповненій реальності

### 🎯 Про проект
Додаток демонструє роботу системи кіберзахисту з використанням:
- WebXR для 3D/AR візуалізації
- Машинного навчання (TensorFlow.js) для детекції аномалій
- Firewall для блокування небезпечного трафіку

### 🖥️ Технології
- Three.js - 3D графіка
- TensorFlow.js - ML модель
- WebXR - доповнена реальність

### 🎮 Функціонал
| Кнопка | Дія |
|--------|-----|
| DDoS Атака | Симуляція розподіленої атаки |
| Сканування портів | Пошук відкритих портів |
| Скинути стан | Очищення статистики |

### 🤖 ML Детекція
- Аналізує: швидкість пакетів, об'єм трафіку, порти
- Визначає рівень: 🟢 LOW / 🟡 MEDIUM / 🔴 HIGH

### 📊 Статистика в реальному часі
- Кількість пакетів
- Заблоковано/дозволено
- Швидкість трафіку
- Унікальні порти
